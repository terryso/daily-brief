会话不再绑窗口

GitHub 的 Agent Host Protocol 让智能体会话跨设备续接

2026-11-18 · 开发工具 · Muse 整理
编辑点评智能体会话不再绑在编辑器窗口上：Agent Host Protocol 由独立进程持有会话，关窗口也不中断；开放标准，六种语言都有现成库。

GitHub 把 Copilot 的智能体会话从编辑器窗口里解放出来，Agent Host Protocol让会话由独立的进程持有，关掉窗口也不会中断。协议是开放标准，六种语言都有现成的库，可以接进自己的编辑器或工具里。
